# 接单与出货双模块差异核对工具

这是一个在浏览器中使用的 Python 工具。接单和出货是两个独立模块：每次只需上传文控登记表和当前模块的两份系统表。程序会同时计算当前模块的人民币、原币结果；页面切换口径时无需重复计算。切换模块后可继续使用已经选择的文控文件，再上传另一模块的两份系统表。

## 五份文件的统一名称

| 中文名称 | 英文名称 | 主要用途 |
| --- | --- | --- |
| 文控登记表 | Document Control Ledger | 同时提供名称含“接单”和“出货”的文控子表 |
| 接单金额明细 | Order Amount Detail | 提供交易金额、接单金额(RMB) |
| 接单运费明细 | Order Freight Detail | 提供出货运费(原币)、出货运费(RMB) |
| 出货金额明细 | Shipment Amount Detail | 提供出货金额、出货金额(RMB) |
| 出货运费明细 | Shipment Freight Detail | 提供出货运费(原币)、出货运费(RMB)及装箱信息 |

五种文件不要求一次全部提交。接单核对只要求“文控登记表＋接单金额明细＋接单运费明细”；出货核对只要求“文控登记表＋出货金额明细＋出货运费明细”。程序只在接单模块读取名称含“接单”的子表，只在出货模块读取名称含“出货”的子表。

## 四组核对结果

### 接单 · 人民币

- 系统金额 = 接单金额明细的 `接单金额(RMB)` + 接单运费明细的 `出货运费(RMB)`
- 文控金额 = 名称含“接单”的文控子表之 `VAT PRICE`
- 运费行追加在接单金额行之后，并放入系统拼接明细的 `接单金额(RMB)` 列

### 接单 · 原币

- 系统金额 = 接单金额明细的 `交易金额` + 接单运费明细的 `出货运费(原币)`
- 文控金额 = 名称含“接单”的文控子表之 `TP-CPO`
- 运费行追加在接单金额行之后，并放入系统拼接明细的 `交易金额` 列

### 出货 · 人民币

- 系统金额 = 出货金额明细的 `出货金额(RMB)` + 出货运费明细的 `出货运费(RMB)`
- 文控金额 = 名称含“出货”的文控子表之 `VAT PRICE`
- 运费行追加在出货金额行之后，并放入系统拼接明细的 `出货金额(RMB)` 列

### 出货 · 原币

- 系统金额 = 出货金额明细的 `出货金额` + 出货运费明细的 `出货运费(原币)`
- 文控金额 = 名称含“出货”的文控子表之 `TP-CPO`
- 运费行追加在出货金额行之后，并放入系统拼接明细的 `出货金额` 列

差异统一等于“系统金额 − 文控金额”。默认差异容差为 1.00，可在页面修改。

出货金额字段同时兼容 `实际出货金额`、`实际出货金额(RMB)` 这类常见表头；中文括号、普通括号及多余空格也会被统一识别。

## 数据追溯与风险提示

- 文控明细保留 BIL、JO、CURR、PART-DWG、工作表名称和原始行号，以及源表中的其他字段。
- 系统明细保留客户代码、订单流水号、交易币种、装箱单号、出厂日期及所有其他原始字段。
- 点击客户代码可查看差异流水号；点击流水号可左右对照文控行和系统行。
- 客户差异汇总和差异流水号中，差异为 0 的行不会显示；完整底稿仍保留在“全部客户汇总”和原始明细中供审计。
- 原币模式发现同一客户代码存在多个币种时会明确提示，因为不同币种不能直接汇总。
- 文控运费行的 JO 为空或为 `-` 时，会在客户代码和原币运费相同的前提下，按最近日期一对一关联相应运费明细的流水号；原始 JO 不会被改写。
- 原始上传文件不会被修改，导出结果是新的 Excel 核对底稿。

## Windows 本机使用

1. 安装 Python 3.14 64 位，并勾选 **Add Python to PATH**。
2. 完整解压本工具。
3. 双击 `start-local.bat`。
4. 首次运行会从 `wheels` 文件夹离线安装依赖，不需要连接外网或公司代理。
5. 浏览器会自动打开 `http://127.0.0.1:8765`。
6. 在左侧选择“接单差异”或“出货差异”，上传该模块要求的三份文件并开始核对。
7. 如需核对另一模块，切换左侧菜单；文控文件无需重新选择，只需补充另一模块的两份系统表。

关闭命令窗口即可停止工具。单次三份文件合计上限为 150 MB，导出下载链接在生成后一小时内有效。

## 公司局域网多人使用

在一台市场部公用电脑或内部服务器上双击 `start-lan.bat`，由 IT 放行 TCP 端口 `8765`。同一局域网同事访问：

```text
http://运行电脑的IP地址:8765
```

建议由 IT 配置固定 IP、开机启动、内部域名和 HTTPS。当前版本没有账号登录，不要直接暴露到公网。

## Excel 导出

当前模块和当前口径均可单独下载 Excel，包含：

1. 差异汇总
2. 流水号差异
3. 全部客户汇总
4. 系统拼接明细
5. 文控接单明细或文控出货明细
6. 核对说明
